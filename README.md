# OSPF Lab

## Objective
Built and configured a three-router OSPF network in Cisco Packet Tracer and verified end-to-end connectivity between two LANs.

## Configured
- OSPF Area 0
- Router IDs
- /30 point-to-point links
- LAN networks
- Loopback interfaces
- Passive interfaces

## Verification
I verified the lab using:
- show ip ospf neighbor
- show ip route ospf
- show ip protocols
- Successful PC-to-PC ping
